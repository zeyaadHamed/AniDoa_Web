# AniDoa — منصة مشاهدة الدونغهوا بترجمة عربية ذكية

**AniDoa** منصة ويب كاملة لمشاهدة الأنمي الصيني (**الدونغهوا — Donghua**) بترجمة عربية احترافية بالذكاء الاصطناعي، تعمل بالكامل مجاناً على **Cloudflare Workers + Cloudflare KV** — بدون أي سيرفر خاص وبدون أي تحميل على جهازك.

> ⚠️ **لا تحتاج جهازك أبداً:** كل خطوات النشر تتم من المتصفح فقط (لوحة تحكم Cloudflare + موقع GitHub). لا يوجد `npm install` ولا أوامر على جهازك.

---

## ✨ المميزات

- **مكتبة مسلسلات**: أضف أي مسلسل مرة واحدة فقط عبر رابط قائمة تشغيل يوتيوب، وتُحفظ حلقاته بالترتيب.
- **مشغل يوتيوب مدمج** مع تعطيل ترجمة يوتيوب الأصلية وتركيب طبقة ترجمة عربية خاصة فوق الفيديو.
- **ترجمة ذكية بـ Gemini 2.5 Flash**: تقسيم إلى دفعات 50 سطراً مع سياق متداخل (آخر سطرين)، وحل مشكلة تقطيع الجمل، وقاموس مصطلحات دونغهوا صارم (تشي، صقل، طائفة...).
- **ترجمة مرة واحدة فقط**: كل حلقة تُترجم مرة واحدة وتُحفظ في KV، ثم تفتح بعدها في أقل من 50ms مجاناً.
- **نظام Fallback من 4 مستويات** لسحب الترجمة الإنجليزية: Innertube ← Piped/Invidious ← Supadata ← رفع ملف SRT يدوياً (الموقع لا يتوقف أبداً).
- **تحكم كامل بالترجمة**: حجم الخط، اللون (أبيض/أصفر)، شفافية الخلفية، مزامنة ±0.5 ثانية — كلها محفوظة في المتصفح.
- **متابعة المشاهدة**: حفظ آخر حلقة + زر الحلقة التالية/السابقة + تشغيل تلقائي للحلقة التالية.
- **حماية المدير**: إضافة المسلسلات محمية بكلمة سر `ADMIN_SECRET` حتى لا يستهلك أحد رصيد الـ API.

## 🏗️ البنية (Architecture)

```
المستخدم (المتصفح)
      │
      ▼
Cloudflare Worker (src/index.js)
  ├── GET /                    → الرئيسية (مكتبة المسلسلات من KV)
  ├── GET /watch               → صفحة المشاهدة + مشغل يوتيوب
  ├── POST /api/series         → إضافة مسلسل (محمي بـ ADMIN_SECRET)
  ├── GET /api/subtitles       → ترجمة عربية جاهزة (من KV أو ترجمة جديدة)
  └── POST /api/translate-manual → ترجمة ملف SRT مرفوع
      │
      ├── YouTube Data API v3  → جلب الحلقات بالترتيب (playlistItems)
      ├── subtitles.js         → سحب الترجمة الإنجليزية (4 مستويات Fallback)
      ├── translator.js        → ترجمة Gemini 2.5 Flash (دفعات 50 + سياق)
      └── Cloudflare KV (ANIDOA_KV)
            ├── series:index          → فهرس المسلسلات
            ├── playlist:{playlistId} → حلقات المسلسل
            └── sub:{videoId}         → الترجمة العربية الجاهزة
```

## 🚀 النشر من لوحة التحكم فقط (بدون جهازك)

### الخطوة 1: إنشاء المستودع على GitHub (من المتصفح)

1. افتح [github.com/new](https://github.com/new) وأنشئ مستودعاً باسم `AniDoa_Web` (عام أو خاص — كلاهما يعمل).
2. ارفع ملفات هذا المشروع من صفحة المستودع: زر **Add file ← Upload files** ثم اسحب كل الملفات والمجلدات (`wrangler.toml`، `package.json`، مجلد `src/`، `README.md`).

### الخطوة 2: إنشاء KV من لوحة Cloudflare

1. سجّل دخولك إلى [dash.cloudflare.com](https://dash.cloudflare.com).
2. من القائمة اذهب إلى **Workers & Pages ← KV**.
3. اضغط **Create namespace** وسمّه `ANIDOA_KV`.
4. انسخ الـ **ID** الذي سيظهر — ستحتاجه في الخطوة التالية.

### الخطوة 3: إنشاء Worker من GitHub

1. من لوحة Cloudflare اذهب إلى **Workers & Pages ← Create ← Workers ← Connect to Git**.
2. اختر مستودع `AniDoa_Web` وامنح Cloudflare صلاحية الوصول إليه.
3. في إعدادات النشر:
   - **Framework preset**: اختر `None` أو اتركه فارغاً.
   - **Build command**: اتركه فارغاً (لا يوجد Build).
   - **Deploy command**: `npx wrangler deploy` (أو اترك الإعداد الافتراضي).
4. قبل أول نشر، عدّل ملف `wrangler.toml` **من موقع GitHub نفسه** (افتح الملف ← زر القلم ✏️):
   - استبدل `REPLACE_WITH_KV_ID` بالـ ID الذي نسخته من الخطوة 2.
   - استبدل `REPLACE_WITH_KV_PREVIEW_ID` بنفس الـ ID.
   - اضغط **Commit changes** — وسيعيد Cloudflare النشر تلقائياً.
5. بديل أسهل للربط: من صفحة الـ Worker اذهب إلى **Settings ← Variables ← KV Namespace Bindings ← Add binding** واختر Binding name = `ANIDOA_KV` والـ Namespace الذي أنشأته.

### الخطوة 4: ضبط الأسرار (Secrets) من Dashboard

من صفحة الـ Worker اذهب إلى **Settings ← Variables ← Add variable** وفعّل خيار **Encrypt** (اجعله Secret) لكل مفتاح:

| المتغير | مطلوب؟ | من أين تحصل عليه؟ |
|---|---|---|
| `YOUTUBE_API_KEY` | ✅ نعم | [Google Cloud Console](https://console.cloud.google.com) — فعّل YouTube Data API v3 ثم أنشئ API Key |
| `GEMINI_API_KEY` | ✅ نعم | [Google AI Studio](https://aistudio.google.com/apikey) — أنشئ مفتاحاً مجانياً |
| `ADMIN_SECRET` | ✅ نعم | أي كلمة سر قوية تختارها أنت (مثلاً `AniDoa-2026-Secret!`) |
| `SUPADATA_API_KEY` | اختياري | [supadata.ai](https://supadata.ai) — مستوى احتياطي ثالث لسحب الترجمة |

> ⚠️ لا تضع المفاتيح أبداً داخل `wrangler.toml` أو في أي ملف في المستودع — Secrets من Dashboard فقط.

### الخطوة 5: النشر والاختبار

1. بعد ضبط الـ KV والأسرار، اضغط **Deploy** أو **Retry deployment** من صفحة الـ Worker.
2. افتح رابط الـ Worker (مثل `https://anidoa.<subdomain>.workers.dev`).
3. أضف أول مسلسل من نموذج "إضافة مسلسل جديد" باستخدام رابط قائمة تشغيل يوتيوب + كلمة سر المدير.
4. افتح أي حلقة — ستُترجم أول مرة خلال دقيقة تقريباً، ثم تفتح بعدها فوراً من الذاكرة.

## 🔑 كيف تحصل على المفاتيح؟

### مفتاح YouTube Data API v3
1. افتح [Google Cloud Console](https://console.cloud.google.com) وأنشئ مشروعاً جديداً.
2. من **APIs & Services ← Library** ابحث عن **YouTube Data API v3** وفعّلها.
3. من **APIs & Services ← Credentials ← Create Credentials ← API key** أنشئ مفتاحاً وانسخه.
4. (اختياري) قيّد المفتاح على YouTube Data API v3 فقط من إعدادات المفتاح.

### مفتاح Gemini
1. افتح [Google AI Studio](https://aistudio.google.com/apikey).
2. اضغط **Create API key** وانسخ المفتاح.
3. الخطة المجانية تكفي للترجمة اليومية المعتدلة.

## 🔄 كيف يعمل نظام سحب الترجمة؟ (Fallback)

| المستوى | الطريقة | متى يُستخدم؟ |
|---|---|---|
| 1 | **Innertube API** (محاكاة تطبيق Android ثم iOS) | الحالة العادية — مباشر وسريع |
| 2 | **Piped / Invidious** (تدوير بين 3+3 سيرفرات) | إذا حظر يوتيوب طلبات المستوى 1 |
| 3 | **Supadata API** | إذا فشلت كل السيرفرات المفتوحة (يحتاج مفتاحاً اختيارياً) |
| 4 | **رفع يدوي** | إذا كانت الحلقة بدون ترجمة (Hardsub) — المستخدم يرفع `.srt` أو يلصق النص ويُترجم فوراً |

## 💰 التكلفة (الخطة المجانية)

| الخدمة | الحد المجاني | استهلاك AniDoa |
|---|---|---|
| Cloudflare Workers | 100,000 طلب/يوم | طلب واحد لكل صفحة + طلب لكل ترجمة جديدة |
| Cloudflare KV | 1,000 كتابة + 100,000 قراءة/يوم | كتابة واحدة لكل حلقة مترجمة، وقراءة سريعة بعدها |
| YouTube Data API | 10,000 وحدة/يوم | ~3 وحدات لكل حلقة عند إضافة المسلسل فقط |
| Gemini 2.5 Flash | حصة مجانية يومية سخية | تُستهلك مرة واحدة لكل حلقة فقط |

النتيجة: **منصة كاملة مجاناً** للاستخدام الشخصي والمتوسط.

## 🛠️ إضافة مسلسل جديد

1. افتح الصفحة الرئيسية وانزل إلى نموذج "إضافة مسلسل جديد".
2. الصق رابط قائمة تشغيل يوتيوب (يجب أن يحتوي على `list=...`).
3. أدخل كلمة سر المدير (`ADMIN_SECRET`) واضغط "إضافة المسلسل".
4. ستظهر الحلقات بالترتيب في المكتبة خلال ثوانٍ.

### حذف مسلسل
حالياً عبر طلب DELETE (من أدوات المطوّر في المتصفح أو أي أداة API):
```
DELETE /api/series?playlistId=PLxxxx
Header: x-admin-secret: <ADMIN_SECRET>
```

## ❓ استكشاف الأخطاء (Troubleshooting)

| المشكلة | الحل |
|---|---|
| "مفتاح YouTube غير مضبوط" | تأكد من إضافة `YOUTUBE_API_KEY` كـ Secret من Settings ← Variables ثم أعد النشر |
| "تم رفض طلب YouTube (403)" | الحصة اليومية انتهت أو المفتاح مقيّد — انتظر لليوم التالي أو أنشئ مفتاحاً جديداً |
| "مفتاح Gemini غير صالح" | تأكد من نسخ `GEMINI_API_KEY` كاملاً من AI Studio |
| "كلمة سر المدير غير صحيحة" | تأكد أن `ADMIN_SECRET` في Dashboard مطابق تماماً لما تكتبه (حساس لحالة الأحرف) |
| "ربط KV غير متاح" | تأكد من ربط `ANIDOA_KV` في `wrangler.toml` ومن Settings ← KV Namespace Bindings |
| الحلقة تظهر "بدون ترجمة إنجليزية" | الحلقة Hardsub أو بلا CC — ارفع ملف `.srt` من نفس الصفحة وسيُترجم فوراً |
| الترجمة متقدمة أو متأخرة | استخدم زرّي ±0.5 ثانية في شريط التحكم — تُحفظ المزامنة تلقائياً |
