# AniDoa — منصة مشاهدة الدونغهوا بترجمة عربية ذكية

[![Tests](https://github.com/zeyaadHamed/AniDoa_Web/actions/workflows/test.yml/badge.svg)](https://github.com/zeyaadHamed/AniDoa_Web/actions/workflows/test.yml)

**AniDoa** منصة ويب كاملة لمشاهدة الأنمي الصيني (**الدونغهوا — Donghua**) بترجمة عربية احترافية بالذكاء الاصطناعي، تعمل بالكامل مجاناً على **Cloudflare Workers + Cloudflare KV** — بدون أي سيرفر خاص وبدون أي تحميل على جهازك.

> ⚠️ **لا تحتاج جهازك أبداً:** كل خطوات النشر تتم من المتصفح فقط (لوحة تحكم Cloudflare + موقع GitHub). لا يوجد `npm install` ولا أوامر على جهازك. الاختبارات التلقائية تعمل على GitHub مع كل تحديث.

---

## ✨ المميزات

- **مكتبة مسلسلات**: أضف أي مسلسل مرة واحدة فقط عبر رابط قائمة تشغيل يوتيوب، وتُحفظ حلقاته بالترتيب (حتى 500 حلقة لكل مسلسل).
- **مشغل يوتيوب مدمج** مع تعطيل ترجمة يوتيوب الأصلية وتركيب طبقة ترجمة عربية خاصة فوق الفيديو، ومحرك تحديد سطر سريع (بحث ثنائي + مسار متسلسل O(1)).
- **ترجمة ذكية بـ Gemini 3.5 Flash-Lite**: تقسيم إلى دفعات 50 سطراً مع سياق متداخل (آخر سطرين)، وحل مشكلة تقطيع الجمل، وقاموس مصطلحات دونغهوا صارم (تشي، صقل، طائفة...)، مع إعادة محاولة تلقائية عند الأخطاء المؤقتة (429/500/502/503).
- **ترجمة مرة واحدة فقط**: كل حلقة تُترجم مرة واحدة وتُحفظ في KV، ثم تفتح بعدها في أقل من 50ms مجاناً.
- **نظام Fallback من 4 مستويات** لسحب الترجمة الإنجليزية: Innertube ← Piped/Invidious ← Supadata ← رفع ملف SRT يدوياً (الموقع لا يتوقف أبداً).
- **تحكم كامل بالترجمة**: حجم الخط، اللون (أبيض/أصفر)، شفافية الخلفية، مزامنة ±0.5 ثانية — كلها محفوظة في المتصفح، مع زر **تحميل الترجمة (.srt)**.
- **متابعة المشاهدة**: حفظ آخر حلقة + زر الحلقة التالية/السابقة + تشغيل تلقائي للحلقة التالية.
- **حماية شاملة**: صفحة المشاهدة تعمل للمكتبة فقط، والترجمة تتطلب عضوية الحلقة في المكتبة، والترجمة اليدوية محمية بكلمة سر المدير، مع حد تقريبي لطلبات الترجمة وترويسات أمان على كل الردود.

## 🛡️ نموذج الحماية (Security Model)

| التهديد | الحماية |
|---|---|
| رابط مشاهدة عشوائي يجبر الموقع على جلب قوائم YouTube واستهلاك الحصة اليومية | صفحة `/watch` تعمل **فقط** لمسلسلات موجودة في KV — لا يُستدعى YouTube API أبداً من رابط مشاهدة، والرابط العشوائي يرجع صفحة 404 عربية |
| طلب ترجمة لفيديو خارج المكتبة | `/api/subtitles` يتطلب `playlist`، ويتحقق أن الحلقة عضو في مسلسل بالمكتبة قبل أي سحب أو ترجمة (404 `NOT_IN_LIBRARY`) |
| استغلال الترجمة اليدوية المجانية | `POST /api/translate-manual` محمي بكلمة سر المدير (`x-admin-secret` أو `adminSecret`) + فحص العضوية (403 عند الخطأ) |
| إساءة استخدام طلبات الترجمة وتكاليف Gemini | حد تقريبي: **15 طلب ترجمة غير مخزّن/ساعة لكل IP** و **500 طلب/يوم إجمالاً** — عند التجاوز يرجع 429 مع ترويسة `Retry-After`. الترجمات المخزنة في KV تتجاوز الحد تماماً |
| هجمات الحقن وسرقة الجلسات | ترويسات أمان على كل الردود: `Content-Security-Policy` (يسمح بيوتيوب والخطوط فقط)، `X-Frame-Options: DENY`، `X-Content-Type-Options: nosniff`، `Referrer-Policy`، `Permissions-Policy`، `Strict-Transport-Security` |
| تخمين كلمة سر المدير عبر التوقيت | مقارنة مقاومة للتوقيت (Constant-Time) لكلمة السر |
| قوائم تشغيل ضخمة تملأ KV | حد أقصى **500 حلقة** لكل مسلسل، مع شارة "أول 500 حلقة" في الواجهة |

> ⚠️ **ملاحظة عن الحد التقريبي:** عدّادات حدود الطلبات تُخزن في KV، و Cloudflare KV **متسق في النهاية (eventually consistent)** — قد تتسابق الزيادات المتزامنة من مناطق مختلفة فتضيع بعض الزيادات، وقد تتأخر القراءة عن الكتابة. الحد يقلل إساءة الاستخدام والتكاليف بفعالية، لكنه لا يضمن حداً دقيقاً بالوحدة.

## 🏗️ البنية (Architecture)

```
المستخدم (المتصفح)
      │
      ▼
Cloudflare Worker (src/index.js)
  ├── GET /                    → الرئيسية (مكتبة المسلسلات من KV)
  ├── GET /watch               → صفحة المشاهدة — المكتبة فقط (لا YouTube API هنا)
  ├── GET /robots.txt          → منع محركات البحث من /api/
  ├── GET /favicon.svg         → شعار AniDoa
  ├── GET /api/health          → الحالة + فحص KV + النموذج النشط
  ├── GET /api/series          → قائمة المسلسلات
  ├── POST /api/series         → إضافة مسلسل (محمي بـ ADMIN_SECRET)
  ├── POST /api/series/refresh → تحديث حلقات مسلسل موجود (محمي بـ ADMIN_SECRET)
  ├── DELETE /api/series       → حذف مسلسل (محمي بـ ADMIN_SECRET)
  ├── GET /api/subtitles       → ترجمة عربية (عضوية + كاش KV + حد الطلبات)
  └── POST /api/translate-manual → ترجمة ملف SRT مرفوع (مدير + عضوية + حد)
      │
      ├── security.js          → ترويسات الأمان + التحقق + مقارنة آمنة + أدوات الحد
      ├── cues.js              → محرك أسطر الترجمة (بحث ثنائي + تصدير SRT)
      ├── YouTube Data API v3  → جلب الحلقات بالترتيب (playlistItems، حد 500)
      ├── subtitles.js         → سحب الترجمة الإنجليزية (4 مستويات Fallback)
      ├── translator.js        → ترجمة Gemini 3.5 Flash-Lite (دفعات 50 + سياق + إعادة محاولة)
      └── Cloudflare KV (ANIDOA_KV)
            ├── series:index          → فهرس المسلسلات
            ├── playlist:{playlistId} → حلقات المسلسل
            ├── sub:{videoId}         → الترجمة العربية الجاهزة
            ├── rl:{ip}:{hour}        → عدّاد الحد لكل IP (15/ساعة)
            └── rl:global:{day}       → عدّاد الحد اليومي العام (500/يوم)
```

## 🚀 النشر من لوحة التحكم فقط (بدون جهازك)

### الخطوة 1: إنشاء المستودع على GitHub (من المتصفح)

1. افتح [github.com/new](https://github.com/new) وأنشئ مستودعاً باسم `AniDoa_Web` (عام أو خاص — كلاهما يعمل).
2. ارفع ملفات هذا المشروع من صفحة المستودع: زر **Add file ← Upload files** ثم اسحب كل الملفات والمجلدات (`wrangler.toml`، `package.json`، مجلد `src/`، مجلد `tests/`، مجلد `.github/`، `README.md`).

### الخطوة 2: إنشاء KV من لوحة Cloudflare

1. سجّل دخولك إلى [dash.cloudflare.com](https://dash.cloudflare.com).
2. من القائمة اذهب إلى **Workers & Pages ← KV**.
3. اضغط **Create namespace** وسمّه `ANIDOA_KV`.
4. انسخ الـ **ID** الذي سيظهر — ستحتاجه في الخطوة التالية.

### الخطوة 3: إنشاء Worker من GitHub

1. من لوحة Cloudflare اذهب إلى **Workers & Pages ← Create ← Workers ← Connect to Git**.
2. اختر مستودع `AniDoa_Web` وامنح Cloudflare صلاحية الوصول إليه.
3. في إعدادات النشر:
   - **Framework preset**: اختر `None` أو اتركه فارغاً.
   - **Build command**: اتركه فارغاً (لا يوجد Build).
   - **Deploy command**: `npx wrangler deploy` (أو اترك الإعداد الافتراضي).
4. قبل أول نشر، عدّل ملف `wrangler.toml` **من موقع GitHub نفسه** (افتح الملف ← زر القلم ✏️):
   - استبدل `REPLACE_WITH_KV_ID` بالـ ID الذي نسخته من الخطوة 2.
   - استبدل `REPLACE_WITH_KV_PREVIEW_ID` بنفس الـ ID.
   - اضغط **Commit changes** — وسيعيد Cloudflare النشر تلقائياً.
5. بديل أسهل للربط: من صفحة الـ Worker اذهب إلى **Settings ← Variables ← KV Namespace Bindings ← Add binding** واختر Binding name = `ANIDOA_KV` والـ Namespace الذي أنشأته.

### الخطوة 4: ضبط الأسرار والمتغيرات من Dashboard

من صفحة الـ Worker اذهب إلى **Settings ← Variables ← Add variable**:

**Secrets** (فعّل خيار **Encrypt** لكل مفتاح):

| المتغير | مطلوب؟ | من أين تحصل عليه؟ |
|---|---|---|
| `YOUTUBE_API_KEY` | ✅ نعم | [Google Cloud Console](https://console.cloud.google.com) — فعّل YouTube Data API v3 ثم أنشئ API Key |
| `GEMINI_API_KEY` | ✅ نعم | [Google AI Studio](https://aistudio.google.com/apikey) — أنشئ مفتاحاً مجانياً |
| `ADMIN_SECRET` | ✅ نعم | أي كلمة سر قوية تختارها أنت (مثلاً `AniDoa-2026-Secret!`) — تحمي إضافة المسلسلات والترجمة اليدوية |
| `SUPADATA_API_KEY` | اختياري | [supadata.ai](https://supadata.ai) — مستوى احتياطي ثالث لسحب الترجمة |

**متغير عادي** (بدون Encrypt):

| المتغير | مطلوب؟ | الوصف |
|---|---|---|
| `GEMINI_MODEL` | اختياري | تجاوز نموذج الترجمة — الافتراضي `gemini-3.5-flash-lite` |

> ⚠️ لا تضع المفاتيح أبداً داخل `wrangler.toml` أو في أي ملف في المستودع — Secrets من Dashboard فقط.

### الخطوة 5: النشر والاختبار

1. بعد ضبط الـ KV والأسرار، اضغط **Deploy** أو **Retry deployment** من صفحة الـ Worker.
2. افتح رابط الـ Worker (مثل `https://anidoa.<subdomain>.workers.dev`).
3. تحقق من الصحة: افتح `<رابط الـ Worker>/api/health` — يجب أن ترى `{"ok":true,"kv":"ok","model":"gemini-3.5-flash-lite",...}`.
4. أضف أول مسلسل من نموذج "إضافة مسلسل جديد" باستخدام رابط قائمة تشغيل يوتيوب + كلمة سر المدير.
5. افتح أي حلقة — ستُترجم أول مرة خلال دقيقة تقريباً، ثم تفتح بعدها فوراً من الذاكرة.

## 🔑 كيف تحصل على المفاتيح؟

### مفتاح YouTube Data API v3
1. افتح [Google Cloud Console](https://console.cloud.google.com) وأنشئ مشروعاً جديداً.
2. من **APIs & Services ← Library** ابحث عن **YouTube Data API v3** وفعّلها.
3. من **APIs & Services ← Credentials ← Create Credentials ← API key** أنشئ مفتاحاً وانسخه.
4. (اختياري) قيّد المفتاح على YouTube Data API v3 فقط من إعدادات المفتاح.

### مفتاح Gemini
1. افتح [Google AI Studio](https://aistudio.google.com/apikey).
2. اضغط **Create API key** وانسخ المفتاح.
3. الخطة المجانية تكفي للترجمة اليومية المعتدلة.

## 🔄 كيف يعمل نظام سحب الترجمة؟ (Fallback)

| المستوى | الطريقة | متى يُستخدم؟ |
|---|---|---|
| 1 | **Innertube API** (محاكاة تطبيق Android ثم iOS) | الحالة العادية — مباشر وسريع |
| 2 | **Piped / Invidious** (تدوير بين 3+3 سيرفرات) | إذا حظر يوتيوب طلبات المستوى 1 |
| 3 | **Supadata API** | إذا فشلت كل السيرفرات المفتوحة (يحتاج مفتاحاً اختيارياً) |
| 4 | **رفع يدوي** (محمي بكلمة سر المدير) | إذا كانت الحلقة بدون ترجمة (Hardsub) — المدير يرفع `.srt` أو يلصق النص ويُترجم فوراً |

## 💰 التكلفة (الخطة المجانية)

| الخدمة | الحد المجاني | استهلاك AniDoa |
|---|---|---|
| Cloudflare Workers | 100,000 طلب/يوم | طلب واحد لكل صفحة + طلب لكل ترجمة جديدة |
| Cloudflare KV | 1,000 كتابة + 100,000 قراءة/يوم | كتابة واحدة لكل حلقة مترجمة، وقراءة سريعة بعدها |
| YouTube Data API | 10,000 وحدة/يوم | ~3 وحدات لكل حلقة عند إضافة المسلسل فقط (المشاهدة لا تستهلك شيئاً) |
| Gemini 3.5 Flash-Lite | حصة مجانية يومية سخية | تُستهلك مرة واحدة لكل حلقة فقط، مع حد 500 طلب/يوم كحماية إضافية |

النتيجة: **منصة كاملة مجاناً** للاستخدام الشخصي والمتوسط.

## 🛠️ إدارة المسلسلات

### إضافة مسلسل جديد
1. افتح الصفحة الرئيسية وانزل إلى نموذج "إضافة مسلسل جديد".
2. الصق رابط قائمة تشغيل يوتيوب (يجب أن يحتوي على `list=...`).
3. أدخل كلمة سر المدير (`ADMIN_SECRET`) واضغط "إضافة المسلسل".
4. ستظهر الحلقات بالترتيب في المكتبة خلال ثوانٍ (حتى 500 حلقة).

### تحديث حلقات مسلسل (عند إضافة حلقات جديدة للقائمة)
عبر طلب POST (من أدوات المطوّر في المتصفح أو أي أداة API):
```
POST /api/series/refresh
Content-Type: application/json

{"playlistId": "PLxxxx", "adminSecret": "<ADMIN_SECRET>"}
```
يُرجع `{"episodeCount": ...}` بعد إعادة جلب الحلقات من يوتيوب.

### حذف مسلسل
عبر طلب DELETE:
```
DELETE /api/series?playlistId=PLxxxx
Header: x-admin-secret: <ADMIN_SECRET>
```

## 🧪 الاختبارات التلقائية

- تعمل **تلقائياً على GitHub Actions** مع كل Push أو Pull Request على `main` (انظر `.github/workflows/test.yml` والشارة أعلى الملف).
- تشمل: فحص صياغة كل ملفات `src/` عبر `node --check`، ثم تشغيل الاختبارات بـ `npm test` (أي `node --test tests/*.test.js`).
- الاختبارات تستخدم **Node built-ins فقط** (`node:test` + `node:assert`) — صفر اعتماديات، ولا تحتاج `npm install`.
- التغطية: أدوات الأمان (`security.test.js`)، محللات الترجمة (`subtitles.test.js`)، محرك الترجمة (`translator.test.js`)، محرك الأسطر (`cues.test.js`)، وواجهات المنصة (`ui.test.js`).

## ❓ استكشاف الأخطاء (Troubleshooting)

| المشكلة | الحل |
|---|---|
| "مفتاح YouTube غير مضبوط" | تأكد من إضافة `YOUTUBE_API_KEY` كـ Secret من Settings ← Variables ثم أعد النشر |
| "تم رفض طلب YouTube (403)" | الحصة اليومية انتهت أو المفتاح مقيّد — انتظر لليوم التالي أو أنشئ مفتاحاً جديداً |
| "مفتاح Gemini غير صالح" | تأكد من نسخ `GEMINI_API_KEY` كاملاً من AI Studio |
| "كلمة سر المدير غير صحيحة" | تأكد أن `ADMIN_SECRET` في Dashboard مطابق تماماً لما تكتبه (حساس لحالة الأحرف) |
| "ربط KV غير متاح" | تأكد من ربط `ANIDOA_KV` في `wrangler.toml` ومن Settings ← KV Namespace Bindings |
| صفحة "المسلسل غير موجود في مكتبة AniDoa" | رابط المشاهدة لمسلسل غير مضاف — أضف المسلسل من الرئيسية أولاً (المشاهدة تعمل للمكتبة فقط) |
| "الحلقة غير موجودة في مكتبة AniDoa" | الحلقة ليست ضمن حلقات المسلسل المحفوظة — حدّث المسلسل عبر `/api/series/refresh` |
| "تم تجاوز حد الترجمة المؤقت (15/ساعة)" | انتظر حتى انتهاء الساعة — العدّاد يظهر في الصفحة مع زر إعادة المحاولة |
| "تم تجاوز الحد اليومي العام (500/يوم)" | الحد اليومي للمنصة انتهى — حاول مجدداً غداً |
| "تجاوزت حد طلبات Gemini مؤقتاً" | Gemini نفسه فرض حداً مؤقتاً — المحرك يعيد المحاولة تلقائياً، وإن استمرت حاول لاحقاً |
| الحلقة تظهر "بدون ترجمة إنجليزية" | الحلقة Hardsub أو بلا CC — ارفع ملف `.srt` من نفس الصفحة مع كلمة سر المدير وسيُترجم فوراً |
| الترجمة متقدمة أو متأخرة | استخدم زرّي ±0.5 ثانية في شريط التحكم — تُحفظ المزامنة تلقائياً |
| `/api/health` يظهر `"kv":"error"` | ربط KV غير صحيح أو Namespace محذوف — راجع الخطوة 2 و3 من النشر |
